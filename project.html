Expense Management System

Overview

This system is for every individual who wants to see how much they earned, how much did they spend or how much did they save. It has very good response to user input. It has its own categories like food, groceries, entertainment, salary and so on. It also has custom option where user can name whatever their expense to be. It shows all thoses data they way user wamts it whether in pie-chart or bar form.

Features

  • Add income
  • Add, edit and delete expenses
  • Group expenses by category
  • View monthly totals

Technologies

As it is just a web based app, I have used JAVA, Database, Css and js.
